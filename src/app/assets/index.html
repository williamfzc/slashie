        Command variables
        
"$SLASHIE_ARGS" passes the text after the prefix. "$SLASHIE_PROMPT" includes that text and the message source.

        
For example, use codex exec "$SLASHIE_PROMPT". A fixed command like echo pong needs no input.

        
A route with "session": "chat" in config.json keeps one agent session per conversation (chat or topic) and passes $SLASHIE_CONTINUE.
